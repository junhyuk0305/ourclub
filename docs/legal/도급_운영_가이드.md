# 도급 운영 가이드 (위장도급 방어)

> ⚠️ **변호사 검토 전 초안입니다.** 런칭 전 전문가 검토 1회는 필수입니다.
> 짝 문서: [표준_프로젝트_용역계약서.md](./표준_프로젝트_용역계약서.md), [README.md](./README.md). 리스크 출처: `B2B_RISK_REMEDIATION_PLAN.md` §R1.

기업↔동아리(프로젝트팀) B2B 거래는 **도급(결과물 납품)** 입니다. 도급이라고 계약서에 적어도, 실제 운영 방식이 '기업이 학생을 지휘·감독하며 사무실에 상주시키는' 형태이면 법원·노동청은 **위장도급 = 실질 파견/고용**으로 재분류합니다. 이 경우 기업이 사용자 책임(임금·4대보험·퇴직금)을 지고, 직업안정법 위반 소지가 생깁니다.

이를 막으려면 **계약서 문구뿐 아니라 실제 운영 방식**이 도급의 외형과 실질을 모두 갖춰야 합니다. 아래 원칙을 기업·동아리 양측이 지켜야 합니다.

---

## 1. 핵심 원칙 (반드시 지킬 것)

| 구분 | ✅ 해야 하는 것 (도급) | ❌ 하면 안 되는 것 (고용/파견 징표) |
|---|---|---|
| **근무 장소** | 동아리가 자율적으로 정한 장소에서 작업. 필요한 회의만 방문. | 기업 사무실 **상시 상주**, 지정 좌석·출입증 부여 |
| **업무 지시** | 기업은 **결과물(과업)** 단위로 요청. 진행 방식·일정·인력 배치는 동아리가 결정. | 기업이 **개별 학생**에게 직접 업무 지시·근태 관리 |
| **소통 창구** | **PL(프로젝트 책임자) 단일 창구**를 통해 소통. | 기업이 팀원 개개인에게 직접 지시·보고 요구 |
| **근태·시간** | 동아리가 자율적으로 작업 시간 관리. | 출퇴근 시간 지정, 근태 기록 요구 |
| **대가 산정** | **산출물·과업 완성** 기준으로 대금 지급. | 투입 시간·인원수(공수) 기준 임금성 지급 |
| **장비·도구** | 원칙적으로 동아리가 자체 장비로 수행. | 기업이 업무 장비·계정을 제공하고 통제 |

> 한 줄 요약: **"기업은 무엇(결과물)을 살지 정하고, 어떻게 만들지는 동아리가 정한다."**

## 2. 단계별 체크리스트

### 기업(발주자)
- [ ] 과업지시서에 **결과물·납기·검수 기준**만 명시한다. 작업 방법·일정·투입 인원을 지정하지 않는다.
- [ ] 커뮤니케이션은 **PL 1인**과만 한다. 팀원에게 직접 지시하지 않는다.
- [ ] 학생에게 사무실 상주·출입증·고정 좌석을 요구하지 않는다. (대면 회의는 가능)
- [ ] 대금은 **산출물 인도·검수** 기준으로 지급한다. 시급·일당·월급 형태로 지급하지 않는다.

### 동아리(프로젝트팀)
- [ ] PL이 기업 창구를 전담하고, 내부 분담·일정은 팀이 자율 결정한다.
- [ ] 작업은 동아리가 정한 장소·시간에 자율적으로 수행한다.
- [ ] 기업으로부터 개별 지휘를 받는 정황(직접 지시·근태 통제)이 있으면 PL이 기업에 도급 원칙을 환기한다.

## 4. 위반 시 위험

위 원칙을 어겨 위장도급으로 재분류되면:

- **기업**: 사용자 책임 발생(임금·퇴직금·4대보험 소급), 파견법·직업안정법 위반 과태료·형사처벌 소지.
- **OURCLUB**: '도급 중개'가 아닌 '인력 공급/직업소개'로 재평가될 위험 → 직업안정법상 무등록 유료직업소개 쟁점.

따라서 도급 운영 원칙은 **선택이 아니라 거래 구조의 전제**입니다.
