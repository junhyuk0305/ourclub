# OURCLUB 법률 서류 패키지 (B2B 프로젝트)

> ⚠️ **전부 변호사·세무사 검토 전 초안입니다.** 런칭 전 전문가 검토 1회는 필수입니다.

기업이 프로젝트를 올리고 동아리가 수주하는 B2B 거래의 책임귀속·계약·수수료를 다루는 문서 묶음입니다.

## 확정된 설계 결정

| 결정 | 선택 | 이유 |
|---|---|---|
| 계약 당사자 모델 | **프로젝트팀 전원 공동(민법상 조합), PL이 대표 창구** | 동아리에 정관·사단 실체가 없어도 성립. 회장 1인 부담 분산. 팀원이 자연스럽게 계약 당사자가 됨 |
| 학생 보호 | **책임 = 계약대금 한도 + 고의·중과실 한정** | 학생이 무한책임 공포 없이 참여하도록 |
| 수수료 부담 | **동아리(프로젝트팀) 부담(성공보수형, 대금 수령 후 납부)** | '인부→인력사무소' 상식 모델. 단 직업안정법 주의(아래) — '팀=사업 수행 주체'로 프레이밍, 개인 소개비 아님 |

## 핵심 법률 쟁점 (검토 시 변호사에게 확인할 것)

1. **직업안정법 (수수료 동아리 부담 시 ★최대 쟁점)** — 거래를 '고용/인력파견'이 아닌 '도급(결과물 납품)'으로 일관되게 프레이밍했는지. **수수료를 동아리가 부담하면 '구직자가 소개비 내는' 유료직업소개로 오인될 위험**이 커진다(구직자 수수료 임금 1% 상한, 무등록 시 처벌). 방어선: ① 수수료 부담 주체를 '개인 학생'이 아닌 '프로젝트팀(사업 수행 단체)'으로 명시, ② 거래를 B2B 도급으로 일관 프레이밍, ③ UI·카피에서 '채용/구인/구직/인력/소개/알선' 표현 전면 금지 → '프로젝트/도급/용역/협업'으로 통일.
2. **전자상거래법** — 통신판매중개업 신고 + '당사자 아님' 고지로 면책 요건 충족.
3. **비법인사단/조합** — 동아리 실체 불요, 민법 §703 조합으로 팀 구성. 팀원 공동 당사자.
4. **세무** — 기업이 학생에게 사업소득 3.3% 원천징수. 동아리는 도관 역할만(돈 보관·재분배 시 소득·증여 이슈 주의).
5. **PG/전자금융** — OURCLUB이 대금을 보관하지 않으므로 결제대행업 등록 의무 회피.

## 용어 규칙 (직업안정법 방어 — 코드·카피 전역 적용)

B2B 거래를 '고용/직업소개'가 아닌 'B2B 도급'으로 일관 프레이밍하기 위해, UI·약관·문서 어디에서도 아래 금지어를 쓰지 않는다.

| ❌ 금지 | ✅ 대체 |
|---|---|
| 채용, 구인, 구직 | 프로젝트 모집, 프로젝트 수주 |
| 인력, 인력 공급, 파견 | 프로젝트팀, 협업 |
| (직업)소개, 알선 | 매칭, 중개 |
| 일자리, 아르바이트 | 프로젝트, 용역, 도급 |
| 근로, 고용 | 도급, 협업 |

> 코드 전반 점검 시 위 금지어를 전수 검색해 교체할 것. 현재 `b2b_projects`, `required_skills`, '제안서', '매칭' 등은 안전. 카피 문구 위주로 확인 필요.
