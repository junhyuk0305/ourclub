# 웹빌더 기능 명세서 (Functional Specification)

> ⚠️ **기획 문서 — 현행 구현과 대조 필요.** 실제 1-Page 웹빌더는 `/workspace`
> (`src/pages/admin/Workspace.tsx`, `src/components/blockKit.tsx`, `src/lib/widgetPresets.ts`).
> 구현 확인된 위젯군: **텍스트 · 통계 · 이미지 · CTA/히어로 · 버튼 · FAQ · 스페이서**(각 스타일 프리셋 + 스크롤 등장 효과 `data-fx`).
> 저장 모델: `club_pages.blocks`(jsonb), 자동 저장(디바운스) + 발행/비공개.
> 아래 항목 중 **Undo/Redo · 본문 폭 프리셋 · 위젯별 SEO 메타**는 미확인(아스피레이션 가능) — 실제 패널과 대조할 것.
> (구 `web.md`("NextBuilder" 12위젯 템플릿)는 타 제품 일반 템플릿이라 폐기함.)

## 1. 공통 시스템 및 기본 규칙
* **드래그 앤 드롭(Drag & Drop):** 위젯 간 배치 순서 변경 및 레이아웃 수정 인터랙션 지원
* **히스토리 관리(Undo/Redo):** 편집 중 작업 단계 복구 및 재실행 기능 (단축키 및 UI 지원)
* **글로벌 스타일 설정:**
    * **본문 폭(Content Width):** 페이지 전체의 최대 너비 프리셋 및 커스텀 설정
    * **페이지 배경:** 전체 배경색(RGB) 및 배경 이미지 지정
    * **기본 텍스트 스타일:** 전체 적용될 공통 폰트, 기본 글자색 설정
    * **공통 버튼 스타일:** 기본 모서리 곡률(Radius), 내부 여백(Padding), 테마 색상 정의
    * **입력 필드 스타일:** 폼 요소의 보더, 배경색, 포커스(Focus) 상태 효과 정의

## 2. 컴포넌트별 상세 기능

### ① 텍스트 블록 (Text Block)
* **편집 인터랙션:** 더블클릭 시 텍스트 편집용 인라인 툴바 활성화
* **타이포그래피:** H1, H2, H3, P 등 사전 정의된 계층 구조 선택
* **텍스트 정렬:** 전체, 좌측, 중앙, 우측 정렬 기능
* **색상 관리:** 개별 글자 색상(RGB) 및 위젯 단위 배경색 설정
* **애니메이션:** 위젯 등장 시 페이드인, 슬라이드 등 효과 적용

### ② 여백 위젯 (Spacer)
* **간격 조절:** 수직 방향 여백 수치(Height) 개별 설정
* **제한 사항:** 최대 여백 수치(Max Height) 제한을 통한 레이아웃 깨짐 방지

### ③ 사진 위젯 (Photo)
* **이미지 업로드:** 로컬 파일 업로드 및 외부 URL 연결
* **편집 기능:** 이미지 크기 조절(%), 모서리 곡률(Radius) 설정
* **웹 접근성:** SEO 및 스크린 리더용 대체 텍스트(Alt Text) 입력
* **링크 연결:** 이미지 클릭 시 이동할 하이퍼링크 설정

### ④ 버튼 위젯 (Button)
* **사이즈 프리셋:** 대(L), 중(M), 소(S) 선택
* **스타일 상세:** 모서리 곡률(px), 내부 여백 수치 조절 (MAX 제한 적용)
* **콘텐츠 편집:** 버튼 내 텍스트 입력(글자수 제한) 및 연결 링크 설정

### ⑤ FAQ 토글 (FAQ Accordion)
* **목록 관리:** 항목 추가/삭제(+/-) 버튼을 통한 개수 제어
* **인라인 에디팅:** 질문(Question) 및 답변(Answer) 영역 즉시 타이핑 편집
* **아코디언 기능:** 클릭 시 답변 영역 노출/숨김 인터랙션

## 3. 관리 및 워크플로우

### ① 저장 및 발행 (Storage & Publishing)
* **임시 저장:** 편집 중인 데이터를 서버/브라우저에 실시간 혹은 수동 저장
* **발행(Publish):** 최종 결과물을 실제 웹 URL에 반영하는 배포 프로세스 분리

### ② 검색 엔진 최적화 (SEO)
* **페이지 메타 설정:** 페이지 제목(Title), 설명(Description) 설정
* **사이트 식별:** 파비콘(Favicon) 업로드 및 OG(Open Graph) 태그 관리

## 4. 개발 및 기술적 고려사항

### ① 구조 및 성능 (Structure & Performance)
* **DOM 트리 최적화:** 위젯 드래그 배치 시 중첩 구조(Deep Nesting)를 지양하고 평면적인(Flat) 레이아웃 구조 유지 로직 구현
* **상태 동기화:** 편집기 내부 상태와 미리보기 화면 간의 실시간 스타일 데이터 정합성 보장

### ② 반응형 디자인 (Responsive Design)
* **브레이크포인트(Breakpoint):** 데스크톱, 태블릿, 모바일 기준의 뷰포트 전환 기능
* **유동적 레이아웃:** 모바일 환경에서의 위젯 수직 쌓기(Stacking) 및 텍스트/사진 크기 자동 최적화 규칙 정의
