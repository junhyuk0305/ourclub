  • 퀵 내비게이션 링크

  • 드래그앤드롭 블록 편집기
  • 위젯 8종 (인트로·텍스트·통계·CTA·이미지·D-Day·갤러리·스페이서)
  • 히어로 · 커버 · 해시태그 편집
  • 테마 컬러 선택
  • 5초 디바운스 자동 저장
  • 발행 / 비공개 전환
  • 라이브 프리뷰 링크
🗂️ 리크루팅 파이프라인
/admin/recruit
  • 칸반 뷰 (드래그로 단계 이동)
  • 리스트 뷰 (정렬·체크박스 멀티 선택)
  • 지원자 상세 모달 (지원서·평가·면접 탭)
  • 단계 이동 시 이메일 발송 (템플릿 편집)
  • 점수 입력·메모·팀 메모 스레드
  • CSV 내보내기 (전체·선택)
  • 이름·전공 검색
  • 모집 공고 전환 드롭다운
📝 지원서 폼 빌더
/admin/form-builder
  • 모집 공고 생성·수정·삭제
  • 공고 상태 관리 (임시저장·모집중·마감)
  • 파이프라인 단계 커스텀 (추가·삭제·순서변경)
  • 질문 추가 (단답·장문형)
  • 질문 드래그 재정렬
  • 필수 여부 설정
  • 발행·재발행 버전 관리
  • 마크다운 모집 요강 작성

/admin/attendance

  • 실시간 출석 인원 카운트
  • 출석 마감
  • 과거 세션 출결 현황 조회
  • 개별 출결 수동 수정 (출석·지각·결석)
👥 부원 관리
/admin/members
  • 부원 목록 테이블 (검색·필터)
  • 기수·직책·역할 인라인 편집
  • 상태 변경 (활동중·수료·탈퇴·활동정지)
  • 출석률 프로그레스 바
  • 이메일로 부원 초대
💼 B2B 프로젝트 지원
/admin/b2b
  • 내 지원 현황 탭 (상태별 배지)
  • 공개 프로젝트 탐색 탭
  • 제안서 작성 (프로젝트 선택·본문 입력)
  • 중복 지원 방지 (지원완료 배지)
💬 Pulse 만족도 조사
/admin/feedback
  • 설문 생성·활성화·종료·재활성화
  • 응답률·평균 점수·점수 분포 차트
  • 개별 응답 목록 (익명)
  • 자유 코멘트 수집

/admin/posts
  • 포스트 작성·수정·삭제

  • SNS 링크 (인스타·노션·카카오)
  • Super Admin 권한 양도
