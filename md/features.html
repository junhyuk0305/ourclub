🚪 운영 시작 분기
/club-setup
  • 부원 가입(→/clubs) / 기존 동아리 합류 / 새 동아리 등록 분기
  • 등록 심사 대기 상태 표시 (검토대기·검토중·보완요청)
  • 합류 승인 대기 상태 표시 (대기중)
  • 대기 중 12초 폴링 → 승인 시 대시보드로
  • 이미 운영진이면 /admin/dashboard 자동 이동
➕ 새 동아리 등록

  • 서류 업로드 (storage: certification-docs)
  • club_registration_requests 제출
  • 보완요청 시 수정 후 재제출
  • 심사 약 2~3주 → 마스터 승인 시 동아리·운영진 생성

👤 마이페이지
/mypage

  • 드래그앤드롭 블록 편집기 (블록킷)

🗂️ 모집·지원 통합 관리
/admin/recruitments · /admin/recruitments/:id
  • 공고 목록 (생성·복제·상태 관리)
  • 공고 상세 4탭: 지원자 / 공고수정 / 지원서수정 / 채용프로세스
  • 지원자: 칸반(드래그) + 리스트(정렬·체크박스) 뷰
  • 단계 이동 시 인앱 알림 발송 (실이메일은 추후)
  • 점수·메모(스레드)·면접질문·태그 · CSV 내보내기
  • 구버전 /admin/recruit · /admin/form-builder → 리다이렉트
