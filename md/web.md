차세대 엔터프라이즈 웹 빌더 위젯 기능 명세서 (v1.0)

문서 개요
본 명세서는 NextBuilder SaaS 플랫폼에서 제공하는 12대 핵심 위젯의 구조와 기능, 속성 제어 요건을 정의합니다. 본 문서는 프론트엔드 컴포넌트 개발 및 우측 속성 패널(Property Panel) UI 설계의 기준이 됩니다.

1. 텍스트 블록

목적: 페이지 내 일반 텍스트, 제목, 단락을 구성하는 기본 단위 요소

캔버스 동작: 더블 클릭 시 인라인 에디팅 활성화

주요 속성 (Properties)

타이포그래피:

글꼴(Font-family), 굵기(Weight) 지정

글자 크기 (기본 단위 PX 제공, MAX, MIN 제한)

텍스트 색상 (RGB 및 브랜드 컬러 팔레트 연동)

SEO 태그 계층: HTML 시맨틱 태그 선택 (<h1> ~ <h6>, <p>)

정렬: 좌, 우, 중앙, 양쪽 정렬

2. 레이아웃 컨테이너 (Layout Container)

목적: 여러 위젯을 묶어 시각적인 구역을 만들고 정렬 기준을 제공하는 부모 요소

캔버스 동작: 빈 컨테이너 영역에 다른 위젯을 드래그 앤 드롭하여 중첩(Nesting) 가능

주요 속성 (Properties)

박스 모델 (Box Model):

너비/높이 (%, px, vw, vh, auto 지원)

여백 (Margin / Padding) 4방향 시각적 제어기

디스플레이 (Display): Flex, Grid 모드 지원

Flex 선택 시: 방향(가로/세로), 주축/교차축 정렬, Gap(간격) 설정

5. FAQ 토글 (FAQ 토글)

목적: 자주 묻는 질문이나 복지 제도 등을 공간 효율적으로 펼치고 접을 수 있는 형태(Accordion)로 제공

주요 속성 (Properties)

아이템 관리: 질문(Title)과 답변(Content) 텍스트 항목 추가/수정

디자인:

열림/닫힘 상태별 배경색 및 텍스트 색상

토글 아이콘 스타일 (+ / -, 화살표 등)

고급(SEO): FAQPage Schema.org 구조화 데이터 활성화 토글 (구글 검색 최적화)

6. 타임라인 (Timeline)

목적: 채용 프로세스, 기업 연혁 등을 시간 순서 또는 단계별로 시각화

주요 속성 (Properties)

노드(Node) 관리: 단계별 제목, 설명, 아이콘 추가 및 순서 변경

레이아웃: 수직 좌측 정렬, 수직 중앙 교차 정렬(Alternative), 수평 슬라이드 정렬

스타일링: 진행/미진행 상태에 따른 선(Line) 및 점(Dot)의 색상, 굵기 설정

8. 글로벌 헤더 (Global Header)

목적: 웹사이트 전역(모든 페이지)에 공통으로 노출되는 최상위 네비게이션

주요 속성 (Properties)

로고 영역: 텍스트 로고 또는 이미지 로고 업로드

메뉴 링크: 이동할 페이지 링크 구조화 및 드롭다운 하위 메뉴 구성

우측 CTA: '지원하기' 등 핵심 버튼 노출 설정

스크롤 동작: 스티키(Sticky) 고정 모드, 스크롤 다운 시 숨김(Smart hide) 모드 지원

9. 슬라이더 (Hero Section)

목적: 안내, 소개 등 여러가지의 핵심적 내용 홍보하고 싶을때 쓰는 슬라이더 배너 영역

주요 속성 (Properties)

배경 (Background): 단색, 그라디언트, 고해상도 이미지

오버레이: 배경 이미지 위의 반투명 색상 덮어쓰기 (가독성 확보용)

콘텐츠: 중앙 정렬된 메인 카피(H1), 서브 카피(P), CTA 버튼 포함 여부

11. 버튼 (Dynamic CTA Button)

목적: 사용자의 특정 행동(클릭)을 유도하는 디자인된 버튼 컴포넌트

주요 속성 (Properties)

클릭 액션 (On-click):

URL 이동 (새 창/현재 창)

입사 지원 폼 모달(Modal) 띄우기

특정 섹션으로 스크롤 이동 (Anchor link)

디자인: 배경색, 테두리, 모서리 둥글기(Radius), 그림자(Shadow), 텍스트

상태 디자인: Hover(마우스 오버 시), Active(클릭 시) 상태의 색상 및 애니메이션 설정
