위 프로젝트 구조를 바탕으로, 요청한 기능의 **구현 계획**을 세워줘.

### 출력 형식

**① 영향받는 파일**
수정/생성이 필요한 파일을 나열하고, 각 파일에서 무엇을 바꾸는지 한 줄로.

**② 구현 순서** (의존성 순)
```
Step 1: [무엇을] → 완료 확인: [어떻게 검증]
Step 2: [무엇을] → 완료 확인: [어떻게 검증]
...
```

**③ DB 변경 필요 여부**
- 필요하면: 테이블/컬럼/RLS 정책 초안
- 불필요하면: "기존 스키마로 충분"

**④ 예상 리스크**
기존 동작에 영향을 줄 수 있는 부분만 (없으면 생략)

**⑤ 예상 소요시간**
각 Step별 예상 시간 (낙관적 / 현실적)
